# NBADraft Backend • NBA Data API (Spring Boot 3)

REST API powering the NBADraft ecosystem.

The backend exposes structured NBA player statistics, contracts, team information, and salary cap data through a modern REST architecture. It consumes datasets generated by the NBADraft Scraper and serves them to frontend applications through documented and optimized endpoints.

## ✨ Key Features

* Automated Data Synchronization
* NBA Player Management
* Team & Roster Management
* Contract Management
* Salary Cap Data Exposure
* OpenAPI / Swagger Documentation
* Lightweight DTO Architecture
* JSON Data Import Pipeline
* RESTful API Design

## 🏗️ Architecture

### Data Ingestion Layer

* JSON dataset consumption
* Automatic database population
* Upsert-based synchronization strategy
* Business-key conflict resolution

### API Layer

* REST Controllers
* Request Validation
* DTO-Based Responses
* OpenAPI Documentation

### Persistence Layer

* Spring Data JPA
* MySQL Database
* Entity Relationships
* Repository Pattern

## 📥 Data Integration

The API is designed to work directly with datasets generated by the **NBADraft Scraper**.

Supported datasets include:

* Players
* Teams
* Contracts
* Statistics
* Headshots
* Team Assets

Data is automatically synchronized and persisted when imported into the application.

## 🔌 Main Endpoints

### Players

```http
GET /api/players
GET /api/players/basic
GET /api/players/{id}
GET /api/players/team/{teamId}
```

### Teams

```http
GET /api/teams
GET /api/teams/{id}
```

### Statistics

```http
GET /api/players/{id}/stats
```

### Contracts

```http
GET /api/players/{id}/contract
```
