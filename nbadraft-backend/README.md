# NBADraft Backend

REST API powering the NBADraft ecosystem.

---

$ Context

This module exposes structured NBA data through REST endpoints and acts as the central communication layer between the data acquisition pipeline and frontend applications.

$ Architecture

The backend follows a layered architecture responsible for persistence, synchronization and data exposure.

Datasets generated by the scraper are imported and synchronized before being consumed through REST APIs.

---

$ Main Endpoints

```http
GET /api/players
GET /api/players/basic
GET /api/players/{id}
GET /api/players/team/{teamId}

GET /api/teams
GET /api/teams/{id}

GET /api/players/{id}/stats

GET /api/players/{id}/contract
```
