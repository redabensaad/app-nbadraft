# NBADraft Frontend

Frontend application providing visualization and simulation tools for the NBADraft platform.

---

$ Context

This module allows users to explore NBA players, contracts, teams and statistics through a modern Angular interface.

It consumes data exposed by the NBADraft Backend API and provides expansion draft simulation workflows.

$ Architecture

The frontend follows a component-driven architecture built with Angular.

Application data is retrieved through dedicated services communicating with the backend API while reactive workflows rely on Signals and RxJS.
